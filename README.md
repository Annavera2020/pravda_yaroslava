# Клио. Правда Ярослава — интерактивный урок истории

Интерактивный урок истории от школы «Клио», урок 1 сезона «Кто решил, что так можно?». Новгород, 1015–1016 годы: обида, месть и ответная месть идут по кругу, пока князь Ярослав не даёт новгородцам грамоту с правилами. Ученик проходит круг мести по Новгородской летописи, читает первую статью Русской Правды и решает дела по закону.

**Живая версия:** _(вставь сюда ссылку после публикации на GitHub Pages, например `https://annavera2020.github.io/pravda_yaroslava/`)_

## О проекте

Урок ведут четыре героя «Клио»: Архивариус, Путешественница, Скептик и Дух архива. В уроке говорит и сам князь Ярослав. Ученик читает историю, проходит по шагам круга мести, решает, как поступят новгородцы, сам читает статью Русской Правды и в конце получает архивную карточку с печатью. Главный вопрос урока: зачем людям записанный закон, если есть старые обычаи? Около 15 минут.

## Функциональность

- 7 экранов: обложка → история → круг мести → источник → суд по Правде → «Подумай» → архивная карточка
- Аудио-озвучка истории: плеер «Слушать», ученик включает по желанию
- Круг мести с кликабельными шагами: обида → месть → ответная месть → новая обида
- Выбор «Как поступят новгородцы?» и блок «Что было на самом деле» по летописи
- Первая статья Русской Правды на древнерусском языке и перевод по кнопке
- Задание «Суд по Правде»: как решит закон в каждом случае
- Три вопроса «Подумай» с отзывом Архивариуса на ответ ученика
- Архивная карточка с понятиями урока и печатью архива
- Ответы сохраняются локально (localStorage)
- Адаптивная вёрстка (телефон / компьютер), поддержка светлой и тёмной темы

## Технологии

Один самодостаточный HTML-файл: HTML + CSS + vanilla JavaScript, без сборки и зависимостей. Иллюстрации встроены как base64. Шрифты — Ruslan Display, PT Serif, PT Sans, Noto Serif (Google Fonts).

## Озвучка

Плеер «Слушать» играет файл `audio/pravda_yaroslava.m4a`. Чтобы заменить озвучку, положи новый файл с таким же именем в папку `audio/` рядом с `index.html` — плеер заработает без правок кода.

## Запуск локально

Файл `index.html` можно открыть прямо в браузере — сервер не требуется.
